# Glance — Desktop Todo Widget ✨

> **Минималистік, әдемі және ыңғайлы жұмыс үстелі виджеті**  
> *Эстетичный и быстрый десктоп-виджет задач для Windows с поддержкой казахского, русского и английского языков.*

---

## 🌟 Басты мүмкіндіктері (Особенности)

### 1. Екі негізгі вкладка (Тапсырмалар және Помодоро)
- **Тапсырмалар (Tasks)**:
  - **Аккордеон мен сілтемелер (Notes & Links)**: Тапсырманы басқанда ашылатын көпжолды сипаттама. GitHub, Jira және құжат сілтемелері автоматты түрде интерактивті түймеге айналып, браузерде бірден ашылады (`shell.openExternal`).
  - **Шағын қадамдар (Mini-Subtasks)**: Әр тапсырманың ішінде чекбокстары мен `[2/4]` прогресс-бары бар подзадачалар.
  - **Екі рет басып өңдеу (Inline Edit)**: Тапсырма мәтінін дабл-клик жасап жедел түзеу.
  - **Түстік басымдықтар (P1 / P2 / P3)**: Қызыл (шұғыл), сары (бүгін), сұр (бэклог).
  - **Фокус-режим (Single Task Focus 🎯)**: Таңдалған іске толық назар аудару үшін қалғандарын күңгірттеу.
  - **Оң жақ батырма мәзірі (Context Menu)**: Көшіру, басымдықты өзгерту, жою.
  - **Авто-мұрағаттау (Auto-Archive)**: «Орындалғандарды тазалау» батырмасы аяқталғандарды `data/archive.json` және адам оқи алатын `data/archive.md` журналына көшіреді.
- **Помодоро таймері (Pomodoro Tab)**:
  - Бөлек арнайы вкладка: үлкен таймер, прогресс-бар және циклдер есептегіші (`1/4`).
  - Режимдер: Фокус (🍅), Қысқа үзіліс (☕), Ұзақ үзіліс (🌴).
  - Байланысқан назардағы тапсырма (Focused task) блогы.
  - Қосымша баптаулар: уақыт ұзақтықтары және дыбыстық хабарлама.

### 2. Шапка және Desktop UX
- **Бекіту (Pin 📌)**: Шапкада орналасқан, жұмыс үстеліне бекіту немесе барлық терезелердің үстінде ұстау режимін ауыстырады.
- **Баптаулар түймесі (⚙️)**: Шапкадан баптаулар модалкасын ашады.
- **Глобалды хоткей (`Ctrl + Alt + N`)**: Кез келген терезеден (браузер, IDE, құжат) жедел жаңа тапсырма жазу өрісіне назар аудару (Quick Capture).
- **Шторка режимі (Roll-up 🔽)**: Шапканы екі рет басу арқылы виджетті жинақы жолаққа айналдыру.
- **Фондық Pomodoro көрсеткіші**: Тапсырмалар вкладкасында жүргенде шапкада таймердің жүріп жатқанын көрсетеді (`🍅 24:30`).

### 3. Баптаулар модалкасы (Settings Modal)
- **Тілдер (i18n)**: 🇰🇿 Қазақша (негізгі) | 🇷🇺 Русский | 🇬🇧 English.
- **Тақырып (Theme)**: ☀️ Жарық (Light) | 🌙 Күңгірт (Dark Obsidian).
- **Орынды құлыптау (Lock Layout 🔒)**: Виджеттің кездейсоқ жылжып кетпеуі үшін замочек тумблері.
- **Акценттік түс (Accent Color)**:
  - 🟣 Classic Lavender (`#6e56cf`)
  - 🔵 Ocean Blue (`#2563eb`)
  - 🟢 Emerald Mint (`#059669`)
  - 🔴 Rose Berry (`#e11d48`)
  - 🟠 Warm Amber (`#d97706`)
  - 🖥️ **Windows Accent Color**: Windows жүйесінің ағымдағы нативті акценттік түсін автоматты түрде пайдалану.
